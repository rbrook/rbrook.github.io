Coldstore

A single-operator command-line archival agent.

Coldstore is a small self-hosted utility that takes periodic snapshots of a working machine and pushes them to a cloud storage bucket belonging to the same operator. Snapshots are deduplicated and encrypted on the machine that creates them, so the storage provider holds ciphertext only.

Design notes

  • Local-first. The agent is a cron-driven shell wrapper around off-the-shelf tools. There is no service, no control plane and no hosted component of any kind.
  • Content-addressed. Repeat runs upload only changed blocks, so a routine snapshot costs seconds and near-zero bandwidth.
  • Least privilege. The storage integration requests the narrowest API scope that will do the job, and is confined to a single directory it creates and owns.

Availability

Coldstore is not a product. It is operated by, and authorised for, one person only. It is not distributed, not accepting users, and has no sign-up.
